What you need

RequirementWhy
macOSCredentials go in the login Keychain and Pigeon runs as a LaunchAgent. Windows and Linux are not supported.
Node.js 24 or newer, and npmpackage.json sets engines.node >=24.
Codex, signed in, with a reachable shared daemonPigeon joins the daemon. codex app-server daemon version should report it.
Permission to install a custom Slack appNeeded once, in the workspace you want to message from.

Install from source

The npm name pigeon belongs to a different project. Do not run npx pigeon. The planned scoped name @pigeon-dev/cli is unpublished.

{{sh:terminal}} $ git clone https://github.com/Murat-Barkin-Kinay/pigeon.git # once the repository is public $ cd pigeon $ npm ci $ npm run build $ node dist/cli.js setup {{/sh}}

If you already have a checkout, skip the clone. To get a pigeon command on your PATH instead of node dist/cli.js, run npm pack and then npm install -g ./pigeon-dev-cli-0.1.0.tgz.

What setup does

  1. Starts a local page on 127.0.0.1 (random port and path, expires after 20 minutes) and opens it. It shows the Slack app manifest and two token fields.
  2. You create the Slack app, install it, and paste two tokens. Slack setup shows each click.
  3. Pigeon validates both tokens with Slack, stores them in Keychain, and prints a one-time line: In a direct message to Pigeon, send: pair <code>.
  4. You send that line to Pigeon in Slack. Pairing locks Pigeon to your user and workspace.
  5. Pigeon installs a LaunchAgent (dev.pigeon.companion), registers its MCP server with Codex and installs its skill. You can close the terminal.

Your first conversation

  1. Open Codex normally in a project and give it a task. Keep it running.
  2. In Slack, open your DM with Pigeon and send sessions.
  3. Pigeon lists live sessions with a Connect button each. Press the one you want.
  4. Reply in that thread: What are you doing?

The message that triggered the selector is not sent after you choose. Send your message again in the thread. Separate threads keep separate projects.

Check the install

{{sh:terminal}} $ node dist/cli.js doctor {{/sh}}

doctor reports Slack pairing, Keychain items, the background service, the Codex runtime and live session count, skill discovery, MCP tool verification, and whether the Slack Socket Mode credential is still valid. If something is wrong, see Troubleshooting.

Uninstall

{{sh:terminal}} $ node dist/cli.js uninstall {{/sh}}

Removes the LaunchAgent, local runtime and state, and the two Keychain items. It does not delete the Slack app (remove that in Slack) or touch Codex settings or history.
