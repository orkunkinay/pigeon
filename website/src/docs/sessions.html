desc: Live, idle, and saved sessions, what reconnection restores, and what resuming does not. ---

No Session Recovery Manager. Pigeon cannot resume a stopped conversation for you. It can only reconnect to sessions that are still loaded in the running Codex daemon. {{pill:no}}

Four states, one rule

StateCan Pigeon talk to it?
Active: loaded in the daemon, a turn runningYes. Status, steering, interruption, approvals.
Idle: loaded in the daemon, waitingYes. Instructions start the next turn in the same session.
Saved: history on disk, not loadedNo. It is not listed and cannot be selected.
Interrupted: a turn you pausedThe session is still live and idle. The turn is not restored.

The rule: a saved conversation is not a live connection. Resuming history may restore the conversation but not a terminated process at the exact instruction where it stopped.

What Pigeon does restore

  • Pigeon restarts ({{pill:ok}}): thread-to-session bindings return and Pigeon rejoins the same live session, with no second worker.
  • Slack reconnects: Socket Mode reconnects automatically; Pigeon catches up the latest agent message of the latest turn. Unsent notifications wait in a durable outbox.
  • Crash during delivery: marked uncertain, warned in the thread, never replayed.
  • Codex daemon restarts ({{pill:exp}}): Pigeon retries discovery and reconnects only to loaded identities; old approval buttons are invalidated.

If your session has stopped

  1. Reopen it in Codex (for example resume the conversation from the Codex CLI or app) so it is loaded again in the shared daemon.
  2. DM sessions to Pigeon and press Connect on it.
  3. Send your instruction in the thread.
{{sh:What you will see when the old session is gone}} You Continue AgentLane. Pigeon That session has gone offline. I haven’t sent your message. Send “sessions” to reconnect explicitly. {{/sh}}

Sleep and network loss

SDK reconnection and the durable outbox are implemented, but physical sleep and network-drop tests have not been run. Slack is not a guaranteed offline inbox. {{pill:exp}}
