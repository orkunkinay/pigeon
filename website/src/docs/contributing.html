desc: Build, test, and the rules for changes. ---

Develop

{{sh:terminal}} $ npm ci $ npm run check # tsc --noEmit $ npm test # tsx --test tests/*.test.ts $ npm run format:check $ npm run build {{/sh}}

Tests never need Slack tokens or a Codex login. They include a real Unix WebSocket fixture, out-of-order RPC correlation, crash recovery without replay, expired queues, ingress authorization and one-use approval controls. Scripts in scripts/ are opt-in experiments against a real Codex and consume normal usage; read them first.

Rules that keep Pigeon trustworthy

  • A runtime adapter exposes only what it can observe and control.
  • Never substitute a resumed transcript for a running worker, retry an uncertain instruction, broaden a security policy, or choose an ambiguous session.
  • Add a regression test for any routing, authorization, persistence or protocol fix.
  • Never put private session logs, local config, tokens or unredacted screenshots in issues, fixtures or commits.

Work on this website

{{sh:terminal}} $ node website/build.mjs # regenerates website/docs/*.html and the search index $ python3 -m http.server -d website 8000 # preview at http://localhost:8000 {{/sh}}

Docs content lives in website/src/docs/*.html, and the Slack diagrams in website/src/shots.mjs. The site uses only relative links, so it works from a GitHub Pages project subpath.

Replacing a diagram with a real screenshot: save it under website/assets/screenshots/, redact tokens, workspace names and personal data first, and reference it with {{img:file.png|alt|caption}}.
