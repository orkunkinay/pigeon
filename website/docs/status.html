    Reference

    Supported, experimental, unsupported

    Evidence collected on 2026-11-18: macOS 15.5 arm64, Node 24.18.0, Codex CLI 0.169.0, shared daemon 0.169.1. This page follows docs/COMPATIBILITY.md and docs/TESTING.md in the repository.

    Verified#

    • Discover a normally opened CLI session, then attach to the same live worker (same thread and turn IDs).
    • Slack → original session → Slack, with a real human Slack message.
    • Steer an active turn; interrupt the exact active turn.
    • Status replies that add no turn and no user item.
    • Human command approval (one-time) and a single-question structured input.
    • Proactive agent messages after you select a session.
    • Pigeon restart rejoining the same live session; LaunchAgent bootstrap and restart.
    • Clean package install into an empty prefix.

    Implemented with restrictions#

    • Status recognition is a fixed phrase list, not natural-language understanding.
    • Completion means the end of a Codex turn, not an arbitrary milestone.
    • Approvals: a single displayable command with no additional permission bundle.
    • Reconnect catch-up covers the latest turn only.
    • Multiple sessions work with separate threads. No stress-scale result.
    • The agent-side MCP tools and skill: a fresh Codex session independently read the skill and sent a real Slack message (docs/awareness-notify-proof.json). They also work from private runtimes such as codex exec; steering does not.

    Experimental#

    • The Codex daemon protocol itself and cross-version behaviour.
    • Recovery after a Codex daemon restart.
    • Mac sleep and network loss.
    • The dedicated Codex desktop app and IDE extensions beyond the observed case.

    Not built#

    • A conversational fork for answering questions beside the main session.
    • A session recovery manager that resumes saved conversations.
    • Remote attachment to private stdio or embedded runtimes; terminal injection.
    • File-change and broad permission approvals from Slack; multi-question forms.
    • Slack file uploads and screenshots.
    • Windows and Linux installation.
    • npm publication (@pigeon-dev/cli is a proposed, unpublished name).

    Cost#

    Pigeon runs on your Mac with SQLite and Slack Socket Mode. There is no cloud worker, tunnel, hosted database, or separate model API. Codex's own usage remains yours. Slack Free allows ten apps and shows the latest 90 days of history.
